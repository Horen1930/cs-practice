\# Состояния локального Git



Рабочая папка - файлы проекта, с которыми я сейчас работаю.



Индекс - изменения, выбранные командой git add для следующего коммита.



Коммит - сохранённая версия подготовленных изменений.



\# Различия Git и GitHub



Git - программа для ведения истории проекта на компьютере. Она позволяет создавать коммиты, ветки и объединять изменения.



GitHub - интернет-сервис для хранения Git-репозиториев, совместной работы, проверки кода и обсуждения изменений.



\# Использованные команды



\- 'git status' - показывает состояние рабочей папки и индекса.

\- 'git diff' - показывает изменения, которые ещё не добавлены в индекс.

\- 'git diff --staged' - показывает изменения, подготовленные для следующего коммита



\# Ветки



Ветка позволяет отдельно работать над изменениями, не затрагивая основную версию проекта.



Новый коммит сохраняется в текущей ветке. Указатель этой ветки перемещается на новый коммит.



При слиянии изменения из одной ветки добавляются в другую.
